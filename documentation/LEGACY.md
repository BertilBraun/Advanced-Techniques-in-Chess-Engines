# Historical implementation evidence

Except for `go-first-rework-architecture.md`, the documents, images, chess
results, and benchmark artifacts in this directory primarily describe the
pre-rework chess platform. They are retained as historical evidence only.

They are not runtime dependencies, current operating instructions, or evidence
for the playing strength or throughput of the Go platform. The authoritative
source snapshot for the removed implementation is the `PreRework` branch at
commit `f8cb82a`.
