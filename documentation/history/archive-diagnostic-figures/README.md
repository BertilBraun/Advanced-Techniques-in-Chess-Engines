# Exploratory TensorBoard diagnostics

These nine figures and their manifest preserve the earlier archive-wide diagnostic export. They include later
continuations and are not the selected-window figures used in the reviewed technical report.

From the repository root, regenerate this historical set from an extracted TensorBoard archive:

```powershell
uv run --group publication python py/tools/render_archived_tensorboard_figures.py --tensorboard-root 'PATH\TO\tensorboard'
```

The default output is this directory. The current publication figures remain in
[`documentation/report/figures`](../../report/figures), generated by `py/tools/render_report_figures.py` and the
other publication renderers documented in the [frozen evidence index](../../evidence/final-chess-20260923/README.md).
